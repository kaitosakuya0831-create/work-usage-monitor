# Work残量リング v1.3.0（Windows回復監視対応・任意）

旧v1.2.1の円形リング、2分自動更新、残り時間カウントダウンを維持。今回の追加は**ローカルWindowsブリッジへの任意送信（既定OFF）**です。設定手順はZIP直下の `README_はじめに.txt` を参照。**Workの自動起動は実装していません。**

---

# v1.2.1から引き継いだ既存機能

Chrome用・非公式・個人向けの拡張機能です。ChatGPT Workの右側「出力」「ソース」欄の下に、5時間・週間の**残り利用枠（％）**を円形リングで表示します。**他の使用量表示拡張機能は不要**です。

## v1.2.0の変更点

- 既存のChatGPT Usage Extension等の画面読取機構を削除。自分のChromeブラウザでログインしているChatGPTのデータを直接読み取ります。
- 表示位置をWorkのサイドパネル幅と合わせ、リング、文字、更新日時、ヘッダーの配置を整理しました。
- ウィジェット表示中のタブで約2分ごとに使用状況を更新します。タブ復帰時（前回取得から一定時間以上）や⟳クリック時にも再取得します。
- 取得失敗時にはエラーを表示し、15分以上更新できない自動取得値は「--」表示にします。
- 元のv1.1.0の表示設定（小型表示、Workのみ表示など）は初回起動で引継ぎ。古い他拡張からの取得値は引継がず、誤った残量を出さないようにしています。明示的な手動値だけ引継ぎます。
- ネットワークへのリクエストは、現在開いているChatGPTサイトの `/api/auth/session` と `/backend-api/wham/usage` に限定。認証情報をローカルストレージに保存したり、第三者サーバへ送信したりしません。

## インストール・更新手順

1. ZIPを解凍し、**`work-ring-extension-v1.3.0`** フォルダを取り出します。その中に `manifest.json` があることを確認してください。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードをONにします。
3. 旧バージョンの「Work残量リング」を**無効化または削除**します。同時にONだとリングが二重に表示されます。
4. **「パッケージ化されていない拡張機能を読み込む」** から `work-ring-extension-v1.3.0` を選択します。
5. `https://chatgpt.com/` にログインしてWorkの画面を開き直してください。原則として「ソース」の下にリングが現れます。

**既存のv1.2.0で設定を維持したい場合：** Chromeに登録済みのv1.2.0フォルダ（Chrome拡張一覧の「詳細」に表示される場所）に、新版フォルダ内のファイルを上書きコピーし、拡張機能一覧で「更新（⟳）」を押してください。これなら拡張IDが変わらず設定を維持しやすくなります。新しいフォルダを別の拡張として読み込むと、Chromeの保存設定は自動では引き継がれません。
6. 以前の**ChatGPT Usage Extensionは不要**です。不要ならChromeの拡張機能一覧から無効にしてください。

## 表示と操作

- **5時間・週間**：ChatGPTが返す使用済み率を `100 - 使用済み率` に変換して残り％表示。片方のウィンドウが提供されないアカウントでは、該当欄だけ `--` です。
- **⟳**：すぐに再取得（通信エラーや取得拒否ならエラー表示）。
- **▣**：小型表示切替。
- **⚙**：リング設定（手入力、月間表示、自動更新切替など）。
- **×**：非表示。Chromeツールバーの拡張アイコンから「表示する」で戻せます。
- ツールバーポップアップ：自動更新ON/OFF、Workのパネルに配置、Work画面のみ表示の切り替え。

## 注意点

- **これはOpenAIの非公式拡張で、実機でのChatGPTログイン状態を使った取得の成功は未検証**です。ローカルの模擬環境では、ネットワーク応答の解析、自動更新、位置合わせを確認しています。
- 使用する `/api/auth/session` と `/backend-api/wham/usage` は**非公開の内部エンドポイント**です。仕様、認証、アクセス制御が変わると、取得できなくなることがあります。403・401・429等のエラーを表示します。取得できない場合に値を推測することはありません。
- 5時間枠が存在しないプラン・Workspaceでは「--」になる場合があります。公式の**設定 → 使用状況**の値を優先してください。
- タブを閉じている間やChromeがスリープ中の間は、この拡張からは定期通信しません。再度タブを表示すると確認します。ChatGPTサーバ側の使用量反映が遅れる場合があります。
- 認証トークンはリクエストに必要な間だけ使い、保存や表示はしません。設定と数値・更新時刻はChromeの`storage.local`に保存します。
- `chatgpt.com`のページ構造が変わるとWork内に埋め込めなくなる場合があります。その場合はポップアップで「Work画面のみ表示」をOFFにして浮動表示を試してください。

## ローカルテスト

```bash
node tests/usage-api.test.js

```

## v1.2.1 追加：リセットまでの残り時間

- 各リングの下に「リセットまで」「あと4時間43分」のようなカウントダウンを表示。週間枠は「あと6日13時間」のように表示します。
- リセット予定時刻は**ChatGPTの使用状況データ内の時刻**をそのまま利用。使用率や固定の5時間・7日からリセット時刻を推測しません。
- 表示はタブが開いている間15秒ごとに再計算。残量のAPI取得周期（通常2分）とは独立しており、カウントダウンのための通信は増やしません。
- リセット日時が提供されなければ「時刻未取得」、到達後は「更新を確認中」。再取得後にサーバ値で更新します。
- リセット予定日時の正確な日付・時刻はカウントダウンにマウスカーソルを当てると確認できます。時計はPCの時刻を利用するため、PCの時計を正確に設定してください。
- 通常表示・コンパクト表示ともにカウントダウンを表示します。

旧バージョン v1.2.0 の利用者は、こちらの `work-ring-extension-v1.2.1` フォルダーを読み込むか、従来の展開フォルダ内のファイルを上書きしてください。新フォルダを別途読み込んだ場合は、古い拡張を無効化し二重表示を防いでください。設定の自動引継ぎはChromeで同じ拡張IDを維持した場合に限ります。
